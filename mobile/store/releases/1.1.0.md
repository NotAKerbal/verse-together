## Changes

Journal autosave and owner-specific draft recovery, conflict/read-only protection; faith-tradition filtering;
saved/default Bibles; JST and chapter comparisons with tablet columns; offline lesson Resources and journal
markers; native study plans; account preferences/reading-position sync, account management and Feedback;
HTTPS scripture links and authenticated study-path generation.

The website retired its old plan UI in 2.18.0. Android's native plans retain the existing account APIs and now
own their pure schedule/scope helpers, using the current shared scripture catalog.
